# music

Backend API for the music application built with Node.js, Express, and MongoDB.

This project provides server-side functionality for the music frontend. It exposes REST API endpoints to manage music data, including artists and related resources. It is intended as an educational backend to support a full-stack music app.

## Frontend Repository

You can find the frontend here:  
https://github.com/aplascenm/music-FrontEnd

## Features

- REST API built with **Express**
- Uses **MongoDB** for data storage
- CORS enabled for connecting to the frontend
- Structured routes and middleware


## Technologies Used

- **Node.js**
- **Express**
- **MongoDB** (via Mongoose)
- **dotenv** for environment variables
- **cors** for cross-origin requests
- **nodemon** for development


## Prerequisites

Make sure you have the following installed:

- Node.js (v16+ recommended)
- npm (comes with Node.js)
- A running MongoDB database (local or hosted)
